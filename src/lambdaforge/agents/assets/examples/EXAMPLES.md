# Installed public API examples

These fixtures use one native Work and a deterministic CPU score, not real training.
`work.yaml` includes explicit ordinary product promotion. `repeated.yaml` and `study.yaml`
demonstrate separate seeds and adaptive design. Tests load these examples as the temporary
importable package `agent_examples`; copy work.py into YOUR installed consumer package and
change the authored run target before use. Do not execute unmodified hidden examples as science.

`inputs.yaml` documents typed binding syntax, not a complete executable Work. Replace exact
Execution/Run identifiers with actual owned evidence; no dataset or product is fabricated.
For ResultInput and ProductInput signatures inspect the installed public types; do not
assume historical evidence can execute or that every checkpoint resumes an epoch.
