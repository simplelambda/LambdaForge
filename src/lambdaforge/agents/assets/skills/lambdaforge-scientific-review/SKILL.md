# Review claims against exact evidence

## Prerequisites and input contract

Claim, exact evidence references, units/fidelity, uncertainty and alternative explanations.

## Procedure

1. Resolve references through native owners; inspect accepted versus censored/predicted/missing support.
2. Separate observed facts, interpretation, hypothesis and unresolved questions, including conditional/joint parameter effects.
3. Write a draft evidence-linked review only with explicit approval, preserving author/status/revision and researcher assessment.

Read [the domain procedure and cases](references/procedure.md) when this task applies.

## Tools and authority

Analysis and notes never authorize further experiments or change the native result store.
Installed signatures/capability availability remain authoritative; a Skill grants no permission.

## Validation

Reference existence is not truth, coverage is not confidence and correlation is not causality. Selection needs complete planned confirmation evidence.
Report concrete observations, exact identities, tests performed and remaining limitations.
