# Orient without executing the project

## Prerequisites and input contract

Absolute pyproject root, research question and any exact existing identity.

## Procedure

1. Read project_info and framework_version; confirm project root/ID independently of the active virtualenv.
2. Page project_structure, find_work_classes and list_project_configs; inspect only the relevant YAML and public signature.
3. Distinguish discovered source paths, validated Works and historical Executions; ask for trust before native consumer imports.

Read [the domain procedure and cases](references/procedure.md) when this task applies.

## Tools and authority

Discovery authorizes neither project writes nor scientific execution.
Installed signatures/capability availability remain authoritative; a Skill grants no permission.

## Validation

Return relevant Work/YAML paths, installed version, exact historical selectors and gaps. Merely finding a class does not validate it.
Report concrete observations, exact identities, tests performed and remaining limitations.
